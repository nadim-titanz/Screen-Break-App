# Screen Break 📱⏸️

A lightweight Android application designed to help you curb excessive smartphone use, manage screen time, and build healthier digital habits.

---

## 📖 About the Project

In today's connected world, it is easy to spend hours mindlessly scrolling. **Screen Break** helps you take back control of your time by actively reminding and encouraging you to take regular breaks from your device.

This project was initially prototyped and developed with assistance from [Google AI Studio](https://ai.google.dev/aistudio).

---

## ✨ Features

- **Break Reminders**: Alerts you when it is time to step away from your screen.
- **Customizable Timers**: Configure work intervals and break durations based on your routine.
- **Enforced Pauses**: Encourages you to set down the phone and rest your eyes before resuming use.
- **Simple & Distraction-Free UI**: Minimalist interface focused on ease of use.

---

## 🚀 Getting Started

### Prerequisites

- [Android Studio](https://developer.android.com/studio) (latest version recommended)
- Android SDK (API Level 26 / Android 8.0 or higher)
- A physical Android device with USB debugging enabled, or an Android emulator

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/nadim-titanz/Screen-Break-App.git](https://github.com/nadim-titanz/Screen-Break-App.git)
   cd Screen-Break-App
Open in Android Studio:

Launch Android Studio.

Select File > Open... and choose the Screen-Break-App folder.

Build and Run:

Allow Gradle to sync dependencies.

Select your target device or emulator.

Click Run (Shift + F10) or the green Play icon.

📋 How It Works
Set Your Target Time: Choose how long you want to use your device before taking a break.

Start Monitoring: Let the app track screen time in the background.

Take a Break: When time is up, follow the prompt to step away and rest your eyes.
